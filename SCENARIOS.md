# Assignment 2: Provided Landing-Page Scenarios

Pick one scenario. Copy its text into your page.

All four are fictional practice situations, not real clients, so there is nothing to research and no one to interview. Every scenario uses the same requirements and rubric. You may change names, wording, and colors, but keep every required item from the assignment.

Each scenario is written in the same order as the starter `index.html`:

| Starter part | What goes there |
| --- | --- |
| `<header>` | Site name and four navigation links |
| `<section id="overview">` | Hero: headline, supporting text, and primary action |
| `<section id="sessions">` | Three feature cards |
| `<section id="about">` | Your content section: About (image and text), gallery, or testimonials |
| `<footer id="contact">` | Footer links, contact line, and copyright |

You may rename an id, for example `sessions` to `activities`, as long as the matching navigation link changes too. The content-section text below is written for an About section with the supplied illustration, `images/practice-book.svg`. If you choose a gallery or testimonials instead, write short fictional captions or quotes in the same voice. No booking system, payment form, real address, or real contact details are needed; `hello@example.com` is a reserved example address that sends nothing.
